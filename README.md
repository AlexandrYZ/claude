# Claude Code — команды и скиллы

Коллекция пользовательских команд и скиллов для [Claude Code](https://docs.anthropic.com/en/docs/claude-code).

## Структура

```
commands/          # Пользовательские slash-команды (/glm, /run_design, ...)
skills/            # Навыки для специализированных задач
agents/            # Кастомные агенты
hooks/             # Хуки жизненного цикла Claude Code
```

## Команды (`commands/`)

| Команда | Описание |
|---------|----------|
| `/glm` | Переключение между Anthropic и GLM API |
